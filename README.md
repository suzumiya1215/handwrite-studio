# 手写字迹填充器 · HandWrite Studio

用**自己的手写笔迹**批量填手写表格的 Windows 桌面工具。

一张「六年级 3 班晨午检表」24 行 × 10 列 = 240 个数字格，手写一遍要 20 分钟以上，还容易抄错；有些场合又必须看着是手写的，打印体不被接受。这个工具的思路是：先把你的每个数字（以及需要的字）手写一遍，采集成本人的字形库；之后对着空白表格 PDF/图片，按参数把字形贴进单元格，一键生成一张「确实是你手写的」表。

> 起因是给基层单位做的一个自用工具，功能范围以 `docs/需求文档.md` 为准。

## 它能做什么

- **采集字形库**：手写采集当前需要的字符，存成 `.hwfont` 字形库
- **填充模板**：载入空白表格（PDF 或图片），框选填表区域，指定行列，批量填充
- **拟真处理**：字形的旋转、缩放、抖动、墨色深浅、笔画粗细都有参数，避免整列字长得一模一样
- **保存工程**：一次配置存成 `.hwpj` 工程文件，下次同一张表直接复用
- **导出**：输出成 PDF / 图片，可直接打印

## 技术栈

| 层 | 依赖 |
|---|---|
| 界面 | PySide6（Qt 6） |
| 图像处理 | OpenCV（headless）、Pillow、NumPy |
| PDF | PyMuPDF |
| 打包 | PyInstaller |
| 测试 | pytest |

架构上 `src/handwrite/core/` **不依赖 Qt**，所以不装 PySide6 也能跑全部单元测试。

## 快速开始

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
python -m pytest tests/ -v
python -m handwrite.main        # 启动界面
```

Windows 下也可以直接双击 `run.bat`。

打包成 exe / 安装包见 `HandWriteStudio.spec` 与 `tools/installer/`。
