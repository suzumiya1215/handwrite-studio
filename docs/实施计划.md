# 实施计划

> 配套文档：《需求文档.md》《数据格式规范.md》《界面原型.html》  
> 本文档回答一个问题：**从哪里开始敲第一行代码，每一步做完能看见什么。**

## 0. 总原则

### 0.1 五条铁律

| 编号     | 原则                  | 为什么                                                                                               |
| ------ | ------------------- | ------------------------------------------------------------------------------------------------- |
| **P1** | **内核先于界面**          | 填充引擎是唯一有技术风险的部分（字形变换、坐标换算、PDF 贴图）。先把它做成命令行跑通的纯函数，界面只是外壳。界面写得再漂亮，内核不对全白干                           |
| **P2** | **每一步都可运行、可验证**     | 不允许"三个模块一起写完再调"。每一阶段结束必须有一个**能双击运行、能看见结果**的产物                                                     |
| **P3** | **测试数据尽早固定**        | 从 M1 开始就准备一份固定的测试素材（一张实拍手写照片 + 一份空白表格 PDF），全程复用。有了固定素材，"改坏了"能立刻发现                                 |
| **P4** | **资源路径从第一天就要"可打包"** | M7 的安装包是 v1.0 的正式交付形式。所有资源（样式表、图标、帮助内容）路径必须走统一函数解析，不允许硬编码绝对路径，否则到 M7 集中爆雷                         |
| **P5** | **接口先写、契约先测**       | 每个模块**先照着 `模块设计说明书.md` 把接口签名和数据对象定下来**，再照 `接口契约与测试用例.md` 写出测试（此时测试是红的），然后填实现直到转绿。**禁止**先随手写实现再补接口 |

**P5 是本轮新增的，也是最容易被忽略的一条**。它带来的好处：

1. **接口错了改起来便宜**——改签名是改几行，改实现是改一整天
2. **并行开发有依据**——M2 和 M3 能同时开工，前提是两边都照着同一份签名写
3. **测试就是验收**——里程碑的"完成"不再是主观判断，而是「这一组测试全绿」
4. **返工可预期**——`test_fill_service.py` 里那条「同 seed 逐像素相同」的断言，能在写代码的第一小时就暴露出随机数设计错误，而不是等到导出对不上

### 0.2 关键路径

```
M1 骨架 ──┬─→ M3 填充内核 ──→ M4 主工作台 ──→ M5 内容与导出 ──┐
          │                                                    ├─→ M7 打包 + 安装包
          └─→ M2 字形采集 ──────────────────────────────────────┘   （必做，非可选）
                     （M6 项目与打磨 与 M4/M5 并行）
```

**并行说明**：M2（采集向导）与 M3（填充内核）互不依赖——采集产出的 `.hwfont` 只要有**任何一个手工造的样例**就能给内核做测试，不必等采集向导写完。这是本项目能压缩总时长的关键。

> 有了 `接口契约与测试用例.md` 里的 `fake_font.py`，M3 甚至不需要等任何真实素材——  
> 程序化生成一套假字形就能把填充引擎的每条分支调完。**这是 M2/M3 能真正并行的技术前提。**

**填充引擎的实现要点（写下来避免踩坑）**：

```python
def render_page(bg, matrix, grid, jitter, font, seed):
    canvas = bg.copy()
    for row in range(grid.rows):
        for col in range(grid.cols):
            if col not in grid.active_cols: continue
            text = matrix[row][col]
            if not text: continue
            # 1) 派生该格的随机源
            rng = np.random.default_rng(seed + row*1000 + col)
            # 2) 先算整格变换（因为整格旋转要以格中心为轴）
            cx, cy = 格中心
            cell_rot = rng.uniform(-jitter.cell.rotate_deg, +jitter.cell.rotate_deg)
            cell_dx  = rng.uniform(-1,1) * jitter.cell.offset_x * 格宽
            cell_dy  = rng.uniform(-1,1) * jitter.cell.offset_y * 格高
            # 3) 逐字渲染到一张"格内图层"（透明底）
            layer = new_transparent(格宽px, 格高px)
            x_cursor = 起始X
            for ch in text:
                glyph = font.pick(ch, rng)          # 随机挑一个样本
                glyph = apply_char_shape(glyph, rng, jitter.char_shape, ch)
                dx, dy = char_pos_offset(rng, jitter.char_pos)
                paste(layer, glyph, x_cursor+dx, base_y+dy)
                x_cursor += glyph.width + spacing + rng jitter
            # 4) 整层旋转 + 平移，再合成到 canvas
            layer = layer.rotate(cell_rot, center=格中心)
            composite(canvas, layer, offset=(cell_dx, cell_dy))
    return canvas
```

**为什么要"格内图层"**：整格旋转必须让**整组字一起转**，不能每个字单独转。必须先把这一格的字合并到一张透明图层上，再整体旋转、再贴到画布。

### M7 · 打包与安装包（v1.0 必做，非可选）

**目标**：产出一个 `.exe` 安装包，**双击 → 下一步 → 装好 → 桌面出现图标 → 能用**。

| 任务                                | 说明                                                                                                                                                        |

| M7.1 `build/HandWriteStudio.spec` | PyInstaller 配置，**用 `--onedir` 不用 `--onefile`**（理由见需求文档 §9.5.1：onefile 每次启动要解压 200MB，首次启动 15~30 秒）。用 `collect_all` 显式收集 PySide6 / cv2 / fitz / numpy / PIL |
| M7.2 `build/app.ico`              | 多尺寸图标（16/32/48/64/128/256），必须是真 `.ico` 而不是改名的 png                                                                                                         |
| M7.3 `build/build_exe.bat`        | 一键打出 `dist/HandWriteStudio/` 程序目录                                                                                                                         |
| M7.4 `build/build_installer.iss`  | Inno Setup 脚本：向导、许可协议、安装目录、快捷方式、文件关联、卸载项                                                                                                                  |

| M7.6 **干净机器测试**                   | 在没装 Python 的机器/虚拟机跑**安装包**（不是跑 exe），走完 §9.5.4 全部 7 条清单                                                                                                    |
| M7.7 使用说明书                        | 一页纸图文：怎么装（含 SmartScreen 提示）、怎么采集、怎么填表、常见问题、怎么卸载                                                                                                           |
| M7.8 交付清单                         | 安装包 + 使用说明 + 一个示例模板 PDF + 一份示例字形库（让用户装完能立刻试）                                                                                                              |

**M7 交付判据**：  
在干净 Win10 上跑安装包 → 装完桌面出现图标 → **双击 5 秒内出首页** → 无黑色控制台窗口 →  
走完采集→填表→导出全流程 → 卸载后安装目录清空、用户数据保留。

**M7 的坑（提前记下）**：

| 坑              | 表现                               | 对策                                                                      |
| -------------- | -------------------------------- | ----------------------------------------------------------------------- |
| 缺 DLL          | 打包后启动报 `ImportError` / 找不到 Qt 插件 | `collect_all` 全部大包；打包后**必须在干净机器测**，本地开发机测不出来                            |
| 资源路径           | 运行时报找不到 `style.qss` / `icons`    | 所有资源路径走统一函数：`base = getattr(sys,'_MEIPASS', 项目根)`，集中在 `core/config.py`  |
| 图标不对           | 桌面图标是白纸                          | 必须是多尺寸 `.ico`；Inno Setup 里 `SetupIconFile` 与 `UninstallDisplayIcon` 都要设 |
| SmartScreen 拦截 | 首次运行弹"Windows 已保护你的电脑"           | 无签名证书不可避免。写进使用说明：「点『更多信息』→『仍要运行』」                                       |
| 360 搬图标        | 装完桌面没图标（本机已知问题）                  | 使用说明里写明「若桌面没图标，去开始菜单找」，或把安装目录加入信任区                                      |
| 卸载删数据          | 用户重装后字形库没了                       | 用户数据在 `%LOCALAPPDATA%\HandWriteStudio\`，与安装目录分离；卸载时询问是否删除               |

## 4. 风险与预案

| 风险                       | 触发信号                     | 预案                                                                                                                          |
| ------------------------ | ------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 3.13 装不上 PySide6         | `pip install` 报错         | 降到 Python 3.12，或改用 PyQt6（注意许可）                                                                                              |
| PyMuPDF 贴图后字迹发虚          | 导出 PDF 放大看是糊的            | 不贴位图，改为 `insert_image` 时给高 DPI 位图；或用 `page.insert_image(rect, pixmap=...)` 显式指定                                             |
| 采集向导太复杂，用户学不会            | 自测走一遍觉得绕                 | 砍掉「拖拽补框」「撤销栈」，只保留"自动框选 + 删除 + 标注"最小闭环                                                                                       |
| 预览大表卡顿                   | 200 行表拖动滑块卡              | 预览只画前 N 行 + 加"正在刷新"占位；导出不受影响                                                                                                |
| `image_editor` 坐标系 bug 多 | 框选位置和鼠标对不上               | 统一用 `QGraphicsScene` 坐标做存储，只在显示时转换；写单测覆盖「屏幕坐标→图像坐标」                                                                         |
| 打包后路径全乱                  | exe 里 `__file__` 指向临时目录  | 所有资源路径走统一函数 `base = getattr(sys,'_MEIPASS', 项目根)`，集中在 `core/config.py`（**注意：`--onedir` 下 `_MEIPASS` 也有效，但更稳的是判断是否 frozen**） |
| Inno Setup 中文乱码          | 安装界面中文变方框                | `.iss` 文件必须存为 **UTF-8 with BOM**，并在 `[Setup]` 段加 `AppName` 等中文字段的编码声明                                                       |
| 安装包装完启动慢                 | 双击后几秒才出界面                | 这是 `--onedir` 的正常表现（3~5 秒）。若超过 10 秒，检查是否误用了 `--onefile`                                                                     |
| 卸载后重装丢数据                 | 用户重装后字形库没了               | 数据在 `%LOCALAPPDATA%`，与安装目录分离；卸载脚本里加「是否删除用户数据」确认框                                                                            |
| 文件关联被占用                  | 双击 `.hwfont` 打不开或打开了别的程序 | `.iss` 里用 `ChangesAssociations=yes`，并在安装时检测已占用关联并提示                                                                         |

## 7. 结语

不要等到 M7 才发现某个资源是硬编码的绝对路径。
